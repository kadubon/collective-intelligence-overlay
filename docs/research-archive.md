The 0.4.4 published tables and the three original offline-reader outputs were
rechecked without network/inference for 0.5.0. SQL was 8/8 at both levels;
composition was 6/8 and 7/8; the nonlearning public rules were 96/96 at each level.
No sensitivity setting or G2/confirmation was established (`assay_not_ready`).
Two real generated candidates were copied into four histories and eight Full/Empty
transfer diagnostics; they are not four independent new capabilities or confirmation.

usage missing. Accumulation effect and CIO added value remain unestimated.

Historical source checking uses the immutable 0.4.4 Git commit; old derivative/raw
hashes are unchanged. It explicitly does not attest the current lifecycle source.
No model generation, additional pilot, parameter search, benchmark or long soak
is performed for the 0.5.0 feature release. Its separate software contract is in
[the implementation register](lifecycle-050-implementation.md).
