## CIO-041-01

Before the fix, real PostgreSQL/OPA/authenticated A2A worker-kill reproductions
at dispatch and after two actual provider completions left UNKNOWN/held with
`receipt_id: null`. Same-ID replay did not execute or recharge; owner review
refused because it required the missing original terminal receipt. The finite
unresolved-effects limit remained blocked.

The fix uses atomic owner anchors in the existing ledger and a distinct v6
receiptless recovery receipt. Legacy cases receive a current observation, never
an invented worker receipt or parent lineage. Review requires the exact retained
request, pinned binding/environment, bounded local/remote descendants and an
installed authoritative read-only physical effect/result/quiescence query. The
original UNKNOWN and allowance remain unchanged. Current closure affects capacity
only; query withdrawal and restore reopen it. See [API](api.md#owner-resolution-of-historical-uncertain-effects)
and [offline upgrade](deployment.md#offline-042-upgrade-and-receiptless-recovery).

Development regressions have exercised new and legacy kills, default capacity 32,
parallel close, exact command replay, actual dump/restore, nested local/remote
children, lost A2A response, partial physical provider work, a fenced live worker,
false quiescence and request/signature tampering. Original failed setup/assertion
attempts are retained. The source-hash-frozen combined proof passed 48 tests with
zero skips in 354.10 seconds on native Windows Python 3.12.14 and owned WSL
PostgreSQL 16.15. All nine physical-case records retain original DSSE/public keys.
The source bytes matched before and after execution. This milestone does not
claim the complete native release matrix has passed.


The synthetic test application's physical witnesses are actual process handles,
