# Security policy

Do not post credentials, private evidence or exploit payloads in public issues.
Use GitHub's private vulnerability reporting for this repository when enabled.
If unavailable, contact the repository owner through a private channel before
disclosing details. No private email address is assumed.

See [threat model](docs/security.md). Supported fixes initially target the latest
0.1.x release. Report the exact version, affected boundary and a minimized safe
reproduction. There is no external audit or vulnerability-free guarantee.
